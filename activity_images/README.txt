This folder stores images for the Activities page.

Structure:
1. Create a subfolder for each activity. The folder name should match the activity title from the CSV, with spaces replaced by underscores (e.g., "Medical Convoy" -> "Medical_Convoy").
2. Inside each subfolder, place your images named sequentially:
   - 001.jpg
   - 002.jpg
   - 003.jpg
   ...

Supported formats: .jpg, .jpeg, .png, .webp, .gif

Example:
activity_images/
  ├── Medical_Convoy/
  │   ├── 001.jpg
  │   └── 002.jpg
  └── Awareness_Campaign/
      ├── 001.png
      └── 002.png
